# 文物脱盐保护闭环服务

这是面向文物保护技师、保护方案审核员和馆藏档案管理员的脱盐处理闭环服务。系统通过 HTTP JSON API 跟踪批次、样本、分阶段方案、处理观测、异常暂停、双人质量批准以及最终档案归存，并保留可查询的审计轨迹。

## 构建

```bash
go build ./cmd/server
```

## 运行

默认监听 `127.0.0.1:19081`。可以使用 `-addr=127.0.0.1:<port>` 或端口号环境变量 `PORT` 覆盖监听端口：

```bash
go run ./cmd/server -addr=127.0.0.1:19081
PORT=19082 go run ./cmd/server
```

服务启动后提供 `/v1/batches` 及其样本、方案、观测、复核、归档和审计子路径。创建批次会执行字段级预检、活动批次与责任人并发冲突检查，并用 `Idempotency-Key` 复用相同请求结果；成功响应回显初始 revision、样本数量和 `BATCH_CREATED` 审计标识。样本支持单对象或数组批量登记，新增样本会原子校验 location、证据和物理指标，返回平均指标变化、受影响方案版本及方案刷新门禁。写请求可通过 `If-Match` 传入批次 `revision`。方案发布需要 `author` 和显式 `confirm`，自定义阶段会经过顺序、阈值方向和目标值门禁，`confirm=false` 仅返回差异预览；观测支持 `observation` 或 `observations` 数组原子导入，返回阶段首末读数、趋势、异常数量和 revision 绑定摘要，连续趋势反转及重复异常会暂停或升级并要求整改证据。完成申请会校验独立责任交接并保存不可变 readiness snapshot；复核要求两名不同审核人覆盖样本证据，退回后必须提供新增证据。批次列表支持状态、阶段、责任人和时间范围筛选并返回统计摘要；审计查询支持 `from`、`to`、`type`、`limit` 与 `cursor` 分页，并返回类型计数和 revision 范围。归档证据索引必须可追溯、非空且不重复。

## 测试与自检

```bash
go test ./...
go run ./cmd/server -addr=127.0.0.1:19081 -self-check
```

`-self-check` 会启动临时 HTTP 服务，完整执行创建批次、观测、阶段锁定、双人批准和归档链路后自行退出。运行服务时会在 `.data` 保存 JSON 快照和 JSONL 审计事件。
